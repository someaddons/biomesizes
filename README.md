# Biome Sizes

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_775502_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/775502.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Biome Sizes is a lightweight minecraft mod which allows you to adjust worldgen settings for biome size per dimension with a simple to use config

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
